Hvad er særligt ved denne kilde?

  • Den eneste kilde med normerede udgiftstal pr. relevante aldersgruppe — kr. pr. 0-5 årig, kr. pr. 67+ årig osv. — der gør det meningsfuldt at sammenligne kommuner med forskellig befolkningssammensætning.

  • Klage- og ankesager pr. 10.000 indb. fordelt på lovgrundlag — en retlig kvalitetsindikator der ikke findes andre steder.
  • Alle serviceområder i ét overblik med benchmark mod sammenligningsgruppe og landsgennemsnit på samme tidspunkt.

Danmarks Statistik — Statistikbanken API

Åbent REST API — ingen token. Danmarks bredeste offentlige statistikkilde med data på kommuneniveau på tværs af befolkning, økonomi, arbejdsmarked, boliger, sundhed, sociale forhold og meget mere. Data hentes via api.statbank.dk/v1.

Ingen autentificering Live data — live pull Tidsserier fra 1971+ api.statbank.dk/v1

Hvad er særligt ved denne kilde?

  • Længste tidsserier: Befolkningsdata fra 1971, indkomst fra 1987, boliger fra 1981 — ingen anden kilde giver denne historiske dybde på kommuneniveau.
  • Kommunale regnskaber for alle kommuner (REGK31): Den eneste kilde til sammenlignelige regnskabstal på funktionsniveau for alle 98 kommuner — grundlaget for benchmarkanalyser.
  • Nettoprisindeks til deflation (PRIS05/PRIS04): Kilden til NPI der bruges til at omregne historiske udgiftstal til faste priser. Ikke tilgængeligt i nogen anden kilde.
  • Meget bredere tematisk dækning end ECO — kriminalitet, kommunalvalg, biblioteker, byggeri, transport, miljø, erhverv og meget mere på kommuneniveau.

Jobindsats API (STAR)

STARs databank — beskæftigelsesindsats og ydelsestal på månedsniveau. Kræver Bearer token. Den eneste kilde med effektmålinger for indsatsen og forløbsvarighed på sagsniveau.

Bearer token påkrævet Månedlig opdatering Lange tidsserier api.jobindsats.dk/v3

Hvad er særligt ved denne kilde?

  • Mest aktuelle ydelsestal: Opdateres månedligt med under to måneders forsinkelse — afgørende til løbende politisk opfølgning.
  • Effektmålinger for indsatsen: Den eneste kilde med mål for overgang til selvforsørgelse inden for 3, 6 og 12 måneder pr. ydelsestype. Disse resultattalmålinger findes ikke i DST.
  • Forløbsvarighed pr. sag: Fordeling på forløbslængde (under 2 uger, 2–8 uger, over 52 uger) — til tidlig identifikation af langvarige sager.
  • Indsatstyper og aktiveringsgrad: Jobsamtaler, vejledningsforløb, virksomhedspraktikker og løntilskud pr. kommune — data om selve indsatsen der ikke findes i DST.

Uddannelsesstatistik API (STIL/UVM)

Børne- og Undervisningsministeriets statistik API. Den eneste kilde med data på skoleniveau — karakterer, trivsel, fravær, kompetencedækning og overgange. Bearer token er aktivt.

Bearer token (langtidsholdbart) Skoleniveau Seneste skoleår: 2024/2025 api.uddannelsesstatistik.dk

Hvad er særligt ved denne kilde?

  • Data på den enkelte skole: Karakterer, trivsel og fravær på skoleniveau — Avedøre Skole, Risbjergskolen osv. separat. Ingen anden kilde giver denne opløsning.
  • Trivselsindikatorer: Social trivsel, faglig trivsel, ro og orden, støtte og inspiration — børns velvære i skolen opdateret hvert skoleår.
  • Kompetencedækning pr. fag: Andel undervisning med fagkompetente lærere — kvalitetsindikator der ikke findes andre steder.
  • Overgange fra grundskolen: Hvad elever fra Hvidovre vælger efter 9. klasse — en nøgleindikator for uddannelsesparathed.

LOIS Statistik PRO2 — Census-kuber (LIFA)

Hvidovre Kommunes interne BI-platform baseret på CPR-registerdata og BBR. Tilgås via Targit BI Designer. Tre kuber: Census Borger, Census DMR, Census Erhverv + Census Prognose.

Intern platform — Targit BI CPR-registerbaseret Månedlig opdatering Kræver kommunal adgang

Hvad er særligt ved denne kilde?

  • Geografisk opløsning til distrikt og adresse: Den eneste kilde der viser befolkningstal, flytninger og boliger pr. skoledistrikt og enkeltadresse. DST og ECO er kun kommuneniveau.
  • Familier og husstande som analyseenhed: Børnefamilier, husstandsstørrelser og aldersprofiler pr. husstand — ikke muligt i DST.
  • Homecomers: Den eneste kilde der identificerer borgere der er vendt tilbage til Hvidovre — inkl. gennemsnitlig fraværslængde.
  • Kommunens egne befolkningsprognoser med boligbyggeprogram: Kan vise befolkningseffekten af konkrete byggerier i specifikke delområder.
  • Erhvervsdata og køretøjer pr. distrikt: CVR-baserede virksomhedsdata og bilregistrering med lokal geografisk præcision.

KMD Insight ØS — Kommunens Økonomisystem

BI-løsning på data fra Hvidovres Økonomisystem (ØS). Én kube: SamletPostering — realiserede posteringer, budget, forventet regnskab og saldo. Tilgås via Targit BI Designer.

Intern platform — Targit BI Direkte fra ØS Op til 5 års historik Kræver kommunal adgang

Hvad er særligt ved denne kilde?

  • Indeværende års faktiske forbrug i realtid: Den eneste kilde med løbende realiserede posteringer. DST's REGK31 er kun tilgængeligt efter regnskabsafslutning.
  • Budget kontra forbrug løbende: Korrigeret budget, restbudget og forbrugsprocent direkte sammenlignet med aktuelt forbrug — afgørende til budgetopfølgning.
  • Forventet regnskab med historik: Den eneste kilde til kommunens egne FVR-versioner — til at spore om den forventede afvigelse har bevæget sig over året.
  • Bilagslink til ØS: Direkte link fra rapport til underliggende bilag — til revision og kontrol.
  • Kobling til DST: Funktionskoderne (F1–F6) er identiske med REGK31 — muliggør direkte sammenligning af indeværende år (KMD) med historik (DST).
